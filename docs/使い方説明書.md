# DeskLauncher 使い方説明書

DeskLauncher は、デスクトップに置いておけるボタン型のランチャーです。ボタンを押すと、あらかじめ割り当てた動作（Web ページを開く、アプリを起動する、文章を貼り付けるなど）を実行します。

---

## 1. はじめに

### インストール

1. `DeskLauncher-Setup-1.0.0.exe` を実行し、画面の案内に従ってインストールします。
2. 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押します。
3. インストールが終わると、画面の右上にランチャーが表示されます。

インストールせずに使いたい場合は、`DeskLauncher-Portable-1.0.0.exe` を好きなフォルダに置いて実行してください。

### 画面の見かた

| 場所 | 役割 |
|---|---|
| 上部の見出し | 今のページ名を表示します。フォルダの中では左に「‹」（戻る）が出ます |
| ⚙ ボタン | 設定画面を開きます |
| ボタン | 押すと割り当てた動作を実行します。右下に点が付いたボタンはフォルダです |
| 下部の点 | ページが 2 つ以上あるときに表示されます。押すとそのページに切り替わります |
| タスクトレイのアイコン | クリックでランチャーの表示・非表示、右クリックでメニューを開きます |

---

## 2. 基本の操作

| やりたいこと | 操作 |
|---|---|
| 動作を実行する | ボタンをクリック |
| フォルダの中を見る | フォルダのボタンをクリック。戻るときは左上の「‹」 |
| ページを切り替える | マウスホイールを回す、または下部の点をクリック |
| ランチャーを動かす | 見出しや余白の部分をドラッグ |
| メニューを出す | ランチャーを右クリック（編集・設定・隠す・終了） |
| ランチャーを呼び出す | ホットキー（初期設定は **Ctrl + Alt + Space**） |
| 設定を開く | ⚙ ボタン、右クリックメニュー、またはタスクトレイのメニュー |

> 💡 ボタンを押しても、それまで使っていたアプリのフォーカスは外れません。そのため「キーを送る」「文字を貼り付け」は、直前まで使っていたアプリに届きます。

---

## 3. ボタンを作る・変える

設定画面の「ボタン」を開きます。左側にランチャーと同じ配置の編集画面、右側に選んだボタンの編集欄が表示されます。変更は自動で保存され、すぐにランチャーに反映されます。

### ボタンを追加する

1. 空いているマスの「＋」をクリックします。
2. 「動作を追加」の一覧から、ボタンにさせたいことを選びます。
3. 右側の欄に URL やファイルの場所などを入力します。
4. 名前の欄にボタンの名前を入力します。
5. 「▶ テスト実行」で動作を確認します。

### 並べ替え・複製・削除

- **並べ替え**: ボタンを別のマスにドラッグします。ボタン同士の場合は入れ替わります。
- **複製**: 編集欄の下にある「複製」を押すと、同じページの空いたマスにコピーが作られます。
- **削除**: 編集欄の下にある「削除」を押します。

### 動作の種類

| 動作 | できること | 入力する内容 |
|---|---|---|
| 🌐 URL を開く | Web ページを開きます | URL、ブラウザ（既定・Chrome・Edge・Firefox・Brave・その他）、シークレットウィンドウで開くかどうか |
| 📂 アプリ・ファイル・フォルダを開く | アプリの起動、ファイルやフォルダを開きます | 場所（「ファイル…」「フォルダ…」で選べます）、起動オプション（任意） |
| ⌨️ コマンドを実行 | コマンドプロンプトの命令を実行します | コマンド、実行するフォルダ（任意）、結果をウィンドウで確認するかどうか |
| 🎹 キーを送る | Ctrl + C などのキー操作を送ります | 「⏺ キーを押して記録」で実際に押すか、一覧から選びます。音量や再生などの特殊キーも選べます |
| 📋 文字を貼り付け | 登録した文章を貼り付けます | 貼り付ける文章、貼り付け後にクリップボードを元に戻すかどうか |
| ⏱️ 待つ | 次の動作まで待ちます | 待つ時間（ミリ秒。1000 で 1 秒） |

### 複数の動作を続けて実行する（マクロ）

1 つのボタンに動作を複数登録すると、上から順に実行します。プログラミングの知識は必要ありません。

**例: メモ帳を開いて定型文を入力する**

1. 📂 アプリ・ファイル・フォルダを開く: `C:\Windows\System32\notepad.exe`
2. ⏱️ 待つ: `1000`
3. 📋 文字を貼り付け: `お世話になっております。`

- 順番は各動作の「↑」「↓」で変えられます。
- スイッチをオフにすると、その動作だけを一時的に飛ばします。
- 途中で失敗した場合は、ランチャーの下部に「○ 番目の動作で失敗しました」と理由が表示されます。

> 💡 ログイン後の画面を開きたい場合は、ブラウザでそのサイトにログインしたままにしておいてください。DeskLauncher はパスワードを保存しません。

### アイコンを選ぶ

| 選択肢 | 内容 |
|---|---|
| 自動 | 最初の「URL を開く」ならサイトのアイコン、「アプリを開く」ならアプリのアイコンを自動で取得します。取れなかったときは「↻ 再取得」を押してください |
| 画像を選ぶ | 手持ちの画像（PNG・JPG・ICO など）を使います |
| 絵文字 | 絵文字を入力するか、一覧から選びます（Windows キー + . で絵文字パネルも使えます） |
| 頭文字 | 名前の 1 文字目をアクセント色の四角で表示します |

「ボタンの色」で、このボタンだけ背景色を変えることもできます。

### ページとフォルダ

- **ページの追加**: 編集画面の上にある「＋ ページを追加」を押します。
- **ページ名の変更**: ページ名をダブルクリックするか、「✎」を押します。
- **ページの並べ替え・削除**: 「←」「→」「🗑」を使います。
- **フォルダの作成**: ボタンの種類で「フォルダ」を選びます。フォルダをダブルクリックするか「📂 フォルダの中を編集」を押すと、中のボタンを編集できます。フォルダの中にもページやフォルダを作れます。上部の「ホーム › …」で元の階層に戻ります。

## 4. 見た目を変える

設定画面の「見た目」を開きます。右側のプレビューと、デスクトップのランチャーにすぐ反映されます。

| 項目 | 設定できる内容 |
|---|---|
| テーマ | ミッドナイト・グラス・さくら・フォレスト・オーシャン・サンセット・モノクロ・ペーパーの 8 種類。選んだあとに細かく調整できます |
| レイアウト | 列（横の数）、行（縦の数）。初期設定は 3 × 3 = 9 個です。アイコンの大きさ、ボタンの間隔、外側の余白、上部の見出しの表示も変えられます |
| 背景 | 単色・グラデーション・画像から選べます。不透明度で透け具合を調整します |
| 枠と角 | 枠の色・濃さ・太さ、全体の角の丸み、ボタンの角の丸み |
| ボタンと文字 | ボタンの色・濃さ、アクセント色、名前の表示、文字の色・大きさ |

> 💡 列や行を減らした場合、入りきらないボタンは自動で次のページに移ります。ボタンが消えることはありません。

## 5. 動作を設定する

設定画面の「動作」を開きます。

### 表示の優先度

| 設定 | 動き |
|---|---|
| 常に一番前 | ブラウザなどを開いても、ランチャーは常に手前に表示されます |
| ふつう | ほかのウィンドウを開くと、その後ろに回ります |
| デスクトップに貼り付け | 常に一番後ろに表示され、デスクトップのアイコンのように使えます |

### 呼び出しホットキー

どの画面からでも、決めたキーでランチャーを一番前に出せます。

1. 「⏺ 変更する」を押します。
2. 使いたい組み合わせ（例: Ctrl + Shift + L）を押します。Ctrl・Alt・Shift・Windows キーのいずれかと一緒に押してください（F1〜F24 は単独でも使えます）。
3. 赤いメッセージが出た場合は、ほかのアプリが同じキーを使っています。別の組み合わせにしてください。

ホットキーをもう一度押すと元の状態に戻ります（「常に一番前」の場合は非表示になります）。

### 起動と操作

| 項目 | 内容 |
|---|---|
| Windows の起動時に自動で起動する | オンにすると、PC を起動したときに DeskLauncher も起動します |
| 起動したときにランチャーを表示する | オフにすると、起動時はタスクトレイにだけ常駐します |
| 位置をロックする | ドラッグで動かないように固定します |
| ボタンを押したらランチャーを隠す | 動作の実行後に、ランチャーを自動で隠します |

## 6. バックアップと移行

設定画面の「バックアップと移行」を開きます。

- **エクスポート**: ボタン・アイコン画像・見た目・動作を 1 つのファイル（.json）に保存します。
- **インポート**: エクスポートしたファイルを読み込みます。読み込む前の設定は自動でバックアップされます。
- **自動バックアップのフォルダを開く**: インポートや初期化の前に残した設定ファイルを確認できます。
- **初期状態に戻す**: すべての設定を最初の状態に戻します（こちらも自動でバックアップされます）。

新しい PC への引き継ぎ方は、ヘルプの「移行手順書」を参照してください。

## 7. 困ったときは

| 症状 | 対処 |
|---|---|
| ランチャーが見当たらない | タスクトレイのアイコンをクリックするか、ホットキーを押してください。画面外にある場合は、DeskLauncher を起動し直すと右上に戻ります |
| ボタンを押すと赤く光る | 動作に失敗しています。ランチャー下部に出る理由を確認し、設定画面で入力内容を直してください |
| 「見つかりません」と表示される | ファイルやアプリの場所が変わっています。「ファイル…」で選び直してください |
| キー送信や貼り付けが効かない | 送り先のアプリを一度クリックしてから、ランチャーのボタンを押してください。管理者として実行しているアプリには届かない場合があります |
| アイコンが絵文字のままになる | ネットワークに接続した状態で「↻ 再取得」を押してください。取れない場合は「画像を選ぶ」か「絵文字」を使ってください |
| ホットキーが効かない | 「動作」画面で赤いメッセージが出ていないか確認し、別の組み合わせに変えてください |
| 終了したい | ランチャーを右クリックするか、タスクトレイのメニューから「終了」を選んでください |

設定ファイルの保存場所（参考）: `%APPDATA%\DeskLauncher\config.json`
