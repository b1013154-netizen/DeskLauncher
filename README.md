# DeskLauncher

デスクトップに置ける、ボタン型のショートカットランチャーです（Windows 用・無料）。
ボタンを押すと、割り当てた動作（Web ページを開く、アプリを起動する、キーを送るなど）を実行します。

## 主な機能

| 分類 | 内容 |
|---|---|
| 動作 | URL を開く（ブラウザ指定・シークレット可）／アプリ・ファイル・フォルダを開く／コマンド実行／キー送信（Ctrl+C、音量、再生など）／文字の貼り付け／待つ |
| マクロ | 1 つのボタンに複数の動作を登録し、上から順に実行（プログラミング不要） |
| ページ・階層 | 複数ページ（ホイールまたは下部の点で切り替え）、フォルダボタンで階層化 |
| 見た目 | テーマ 8 種、背景（単色・グラデーション・画像）、枠の色・太さ、角丸、透明度、アイコンの大きさ、列×行（初期値 3×3 = 9 個） |
| 表示の優先度 | 常に一番前／ふつう（ほかのウィンドウの後ろに回る）／デスクトップに貼り付け（常に最背面） |
| ホットキー | 自分で決めたキー（初期値 Ctrl + Alt + Space）でランチャーを一番前に呼び出す |
| アイコン | 自動取得（サイトのアイコン・アプリのアイコン）／画像を選ぶ／絵文字／頭文字 から選択 |
| 移行 | 設定を 1 ファイルにエクスポート・インポート（アイコン画像も含む）。手順は [docs/移行手順書.md](docs/移行手順書.md) |
| 説明書 | [使い方説明書](docs/使い方説明書.md) と [移行手順書](docs/移行手順書.md) を同梱。設定画面の「ヘルプ（説明書）」やタスクトレイの「使い方（説明書）…」から読めます |
| その他 | タスクトレイ常駐、Windows 起動時の自動起動、位置のロック、実行後に隠す、自動バックアップ |

キー送信と文字の貼り付けは、ランチャーを押す直前に使っていたアプリに届きます（ランチャーはクリックしてもフォーカスを奪いません）。

## インストール

GitHub の Actions タブ →「Windows build」の最新の実行結果 → Artifacts の `DeskLauncher-Windows` をダウンロードして展開します。

- `DeskLauncher-Setup-x.y.z.exe`: インストーラー（スタートメニューとデスクトップにショートカットを作成）
- `DeskLauncher-Portable-x.y.z.exe`: インストール不要版

初回起動時に「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押してください（コード署名をしていないために表示されます）。

## 使い方

- **ボタンを押す**: 割り当てた動作を実行します。フォルダボタンは中のボタンを表示し、左上の「‹」で戻ります。
- **移動**: 見出しや余白をドラッグします（「位置をロック」中は動きません）。
- **右クリック**: 「編集」「設定を開く」「隠す」「終了」のメニューを表示します。
- **設定**: ランチャーの ⚙、右クリックメニュー、タスクトレイのいずれかから開きます。変更はすぐにランチャーに反映され、右上の「💾 保存」（Ctrl + S）でファイルに保存されます。

## 開発者向け

```bash

npm install
npm start          # 開発用に起動
npm run check      # 構文チェックと設定モジュールのテスト
npm run dist       # Windows 上でインストーラーとポータブル版を作成（dist/）
```

| ファイル | 役割 |
|---|---|
| `src/main.js` | ウィンドウ・タスクトレイ・ホットキー・設定の保存と反映 |
| `src/actions.js` | 各動作の実行（マクロは上から順に実行） |
| `src/win32.js` | Windows API（キー送信、最背面固定）を [koffi](https://koffi.dev/) で呼び出す |
| `src/config.js` | 設定の既定値・検証・エクスポート形式（Electron 非依存、`scripts/test-config.js` でテスト） |
| `src/icons.js` | アイコンの自動取得と画像の取り込み |
| `src/renderer/` | ランチャー本体と設定画面（HTML / CSS / JS、フレームワーク不使用） |

設定は `%APPDATA%\DeskLauncher\config.json` に保存されます。上書き前の設定は `backups\` に自動で残ります。
